# Repository contents

| Folder | What it is |
|---|---|
| `website/` | Generated, deploy-ready printing & packaging website (open `website/index.html`) |
| `website-src/` | Source and build tooling for the website – edit `config.py` and `content/` then run `python3 build.py` (see `website-src/README.md`) |
| `leads/` | Research database of 662 Sri Lankan organisations that buy printing and packaging, with a CSV and an outreach playbook (see `leads/README.md`) |
| `index.html`, `script.js`, `styles.css` | Pre-existing Facebook Ads dashboard, unchanged |
